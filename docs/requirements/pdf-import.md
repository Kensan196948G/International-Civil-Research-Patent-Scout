# PDF 本文抽出（FR-204）運用方針

## 1. 目的

手動文献登録（`/feed` の「手動で文献を登録（特許・論文・Web・PDF）」）で、
PDF ファイルの本文を抽出して `source_documents.body_text` へ保存できるようにする。

## 2. 事前確認（サイズ・形式・利用条件）

| 項目 | 制限・方針 |
| --- | --- |
| サイズ | 20MB 以内（超過時はエラー表示・抽出しない） |
| 形式 | `application/pdf` または `%PDF-` マジックバイトで判定 |
| ページ数 | 先頭 30 ページまで抽出 |
| 文字数 | 30 万文字まで（超過分は切捨てて `truncated` を表示） |
| 実行場所 | ブラウザ側（pdfjs-dist）。本文はユーザー操作でサーバーへ送信 |

## 3. ライセンス確認（保存範囲の制御）

- 本文を保存する場合は「本文の保存を許諾するライセンスがあります」チェックが必須
- **ライセンス不明の PDF はメタデータのみ保存**（`body_text` は保存しない）
- サーバー側でも `POST /api/documents/import` が `bodyText` と
  `licenseConfirmed: true` の組合せ以外を 400 で拒否する（fail closed）
- 保存時の `license_note` は「利用許諾確認済み（ユーザー申告・本文保存）」、
  メタデータのみの場合は従来どおり「公開メタデータ・要旨を中心に利用（本文は原則保存しない）」

## 4. 受け入れ条件

- ライセンス不明 PDF はメタデータのみ保存される（API テストで固定）
- 20MB / 30 ページ / 30 万文字の制限が機能する
- 抽出失敗時は本文なしでメタデータ登録を継続できる（エラーは UI に表示）
