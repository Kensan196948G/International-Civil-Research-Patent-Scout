## 2. 強み（15件）

1. 検索→保存→要約→比較→レポート→ウォッチまで一気通貫の業務フロー
2. 土木分野に特化した日英キーワード辞書と自動展開
3. 公的一次情報コネクタ（Crossref / OpenAlex / J-STAGE / 土木研究所 / ITC / 国交省 / 関東地整）
4. LLM キー未設定・外部 API 障害時でも落ちないフォールバック設計
5. Cloudflare Workers + Neon PostgreSQL の低コスト・サーバーレス構成
6. 全主要操作の監査ログ
7. systemd 自動再起動・5分間隔ヘルスチェック
8. 日次バックアップ＋件数突合検証スクリプト
9. ユーザー/プロジェクト/チームの 3 層ロールと所有権チェック
10. シークレットのリポジトリ外管理（0600 / GitHub Secrets）
11. strict TypeScript・eslint 0・npm audit 0
12. API 100 件・Web 15 件の自動テスト
13. Runbook / SLO / 運用台帳を含む充実した運用手順
14. DOI・特許番号・URL・ハッシュによる重複排除と IPC 正規化
15. v0.10.0 で登録制御・AI コスト管理・要約レビュー永続化を追加
