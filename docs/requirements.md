# 要件概要

正式な要件定義は [要件定義書 PDF](../要件定義International_Civil_Research__Patent_Scout.pdf) を参照。

## 目的

国内外の土木技術、工法、材料、特許、論文、技術資料を横断的に検索・収集・要約し、研究開発、技術提案、工法比較、技術調査の初期検討を効率化する。

## 非機能要件の対応状況

| 要件 | 対応 |
| --- | --- |
| NFR-001 検索 10 秒以内 | 外部 API タイムアウト 8 秒・並列実行 |
| NFR-101 月間稼働率 99% | systemd 自動再起動 + ヘルスチェック |
| NFR-102 外部 API 障害時継続 | コネクタ単位で失敗を分離し継続 |
| NFR-201 HTTPS | Cloudflare 移行時に適用（ローカルは HTTP） |
| NFR-202 認証情報の保護 | bcrypt + JWT、シークレットは環境変数 |
| NFR-203 権限管理 | 所有者チェック + admin ロール |
| NFR-204 ログ保存 | audit_logs + Cloudflare Workers ログ（将来） |
| NFR-301〜304 コンプライアンス | 引用明示・免責表示・robots 配慮 |
| NFR-401〜404 保守性 | コネクタプラグイン方式・テスト・CI |
