# v0.5.0 — ブックマーク一覧・類似スコア改善・引用ネットワーク・ファセット絞り込み

リリース日: 2026-08-05（ローカル本番適用済み）

## 追加機能

- **保存済み検索（★ブックマーク）の専用一覧画面**
  - 検索ページ上部に「保存済み検索」カードを追加（クリックで再検索・ワンクリック解除）
  - `GET /api/search/bookmarks` を利用
- **類似文献スコアの精度向上**
  - 出願人（表記ゆれ正規化: 株式会社/（株）/Inc.）・発明者・技術分類コード（IPC/CPC）の一致を加点
  - Espacenet OPS から IPC/CPC 分類を取得し `source_documents.classifications` に保存（マイグレーション 0006）
  - 類似検索のテキストにも分類・出願人を反映
- **引用・被引用ネットワーク（Cited-by）**
  - Crossref（被引用数・参考文献 DOI）＋ OpenAlex（被引用数・引用元タイトル）を取得
  - 文書詳細「引用ネットワーク」タブに被引用数・参考文献・引用元リストを表示
  - 新規 API: `GET /api/documents/:id/citations`
- **ファセット絞り込み**
  - 検索結果を種別（論文/特許/Web）・国・特許ステータスでリアルタイム絞り込み
  - 各ファセットに件数表示・「クリア」ボタン・表示件数表示
  - `SearchResultItem.country` を追加し、検索結果に国を保持
