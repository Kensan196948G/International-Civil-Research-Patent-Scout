# v0.1.2 — 土木建設技術文献データ連携（自動収集）

リリース日: 2026-08-01（予定）

## 追加機能

- **土木建設技術文献の自動収集**（2時間ごと・systemd timer）
  - J-STAGE（公式 WebAPI: 土木・建設・構造を対象に直近2年分の論文メタデータ）
  - 土木研究所 論文・刊行物検索（新着一覧）
  - ITC Digital Library（年別一覧 + 詳細ページ・増分取得・上限100件/回）
  - 国土交通省 技術調査 / 関東地方整備局 技術情報（記事リンク）
- **管理画面「文献データ連携」**（システム設定内）
  - 各ソースの最終取得結果（取得件数・新規登録・重複）と履歴表示
  - 「今すぐ取得」ボタン（管理者のみ）
- **保存フローの実装**（検索結果・フィード・文書詳細）
  - 「プロジェクトに保存」/「保存」ボタンから保存先プロジェクトを選択して保存
  - 保存後はフィード・プロジェクト画面へ即時反映、結果メッセージを表示
  - プロジェクト未作成時は作成を促す案内を表示
- **技術文献フィードへの収集文献掲載**
  - フィード上部に「保存文献 / 収集文献（土木建設技術）」のタブを追加
  - 収集文献は情報源（J-STAGE / 土木研究所 / ITC / 国交省 / 関東地整）とキーワードで絞り込み可能
  - カードにタイトル・原題・著者・掲載誌/資料名・公開日・DOI・要旨（取得分）・出典URLを表示し、詳細画面への遷移・プロジェクト保存に対応
  - 追加 API: `GET /api/literature`（ページング・最大100件/回）
- **管理者 API**: `GET /api/admin/ingest/runs` / `POST /api/admin/ingest/run`
- 一括登録 `insertDocumentsBatch`（content_hash の一意制約で重複排除・ON CONFLICT DO NOTHING）
- **文書詳細クリック不具合の修正**（検索結果・フィードで行ごとの文書へ遷移するよう修正）

## 方針

- 保存するのはメタデータのみ（本文・PDF は保存しない）
- robots.txt・取得間隔・レートを尊重（ITC は詳細ページ間 0.5 秒以上・100件/回上限）
- PATENTSCOPE / J-PlatPat は自動取得対象外（認証・契約・レート制限）。手動取り込み UI は後日検討
