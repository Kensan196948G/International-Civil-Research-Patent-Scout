# v0.6.0 — 年ファセット・引用グラフ・分類コード標準化・特許ファミリー

リリース日: 2026-08-05（ローカル本番適用予定）

## 追加機能

- **ファセットに公開年レンジを追加**
  - 検索結果の絞り込みに発行年（FROM–TO）を追加
- **引用ネットワークのグラフ可視化**
  - 文書詳細「引用ネットワーク」タブに SVG グラフを追加（中央＝この文献、緑＝引用元、青＝参考文献）
  - ノードクリックで原典（DOI / OpenAlex）を開く
- **分類コード（IPC/CPC）の標準化**
  - `E04G 23/00` → `E04G23/00` 形式に正規化し、重複排除・無効コード除去
  - Espacenet OPS 取得時と DB 保存時に適用（`normalizeClassifications`）
- **特許ファミリー・優先権マップ**
  - Espacenet OPS の INPADOC ファミリー取得（キー設定時）・ファミリー ID 表示
  - 未設定・失敗時は保存文献から類似度の高い特許を「同族候補」として表示
  - 特許文書に「特許ファミリー」タブを追加（公開番号・国・公開日・タイトル・出願人）
  - 新規 API: `GET /api/documents/:id/patent-family`
