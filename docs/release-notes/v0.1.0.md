# Release Notes v0.1.0（2026-07-31）

## 概要

International Civil Research & Patent Scout の MVP をローカル環境（systemd + Neon PostgreSQL）でリリース開始。

## 新機能

- ユーザー登録・ログイン（bcrypt + JWT）
- 調査プロジェクト管理（作成・編集・アーカイブ・タグ）
- 横断検索（Crossref / OpenAlex / Google Patents / DuckDuckGo / SerpAPI）
- 重複排除・関連度スコアリング
- AI 要約（OpenAI 互換 API / ルールベースフォールバック）
- 比較表生成・編集
- 5 テンプレートの Markdown レポート生成・エクスポート
- ダッシュボード統計
- 管理画面（ユーザー・監査ログ）
- systemd 自動起動・ヘルスチェック・スモークテスト

## デプロイ

- WebUI/API: `http://192.168.0.185:8787`（0.0.0.0 バインド）
- DB: Neon PostgreSQL（aws-ap-southeast-1）
- Cloudflare サブドメイン: 後日決定（mirai-dx-platform.com 配下）

## 既知の制限

- 検索は同期実行（外部 API 応答時間に依存。Phase 2 でキュー化）
- Google Patents はメタデータのみ・HTML パースのため best-effort
- Web 検索は DuckDuckGo HTML（SERP_API_KEY 未設定時）でレート制限の影響を受ける
- 更新監視・通知、チーム共有、PDF 抽出、Word/PDF 出力は未実装（Phase 2/3）
- ローカル稼働のため HTTPS は Cloudflare 移行後に適用
