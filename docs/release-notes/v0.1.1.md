# Release Notes v0.1.1（2026-08-01）

## 概要

リリース直前の堅牢化・運用準備バージョン（Draft PR 時点の計画値）。

## 変更内容

- 認証エンドポイントにレート制限を追加（登録: IP あたり 10 回/時、ログイン: IP+メールあたり 10 回/15 分）
- メールアドレスの正規化（trim + 小文字化）
- 全レスポンスに `X-Request-Id` を付与し、エラーログにリクエスト ID を記録
- systemd 死活監視 timer（5 分間隔・失敗時自動再起動）を導入
- Dependabot（npm / GitHub Actions）設定を追加
- インシデント対応手順書・記録テンプレートを追加
- `npm run clean` を追加し、古い `tsbuildinfo` による差分ビルド不具合を防止
- **WebUI を「ICRPS WebUI (standalone).html」の内容へ 100% 適用**（ルート直下の設計成果物を React コンポーネントへ機械変換し、実 API と接続）
  - サイドバー（リサーチ / AI 分析 / 管理）・ヘッダー・11 画面（ダッシュボード / フィード / 検索 / 文書 / 比較 / FIT / レポート / チャット / 更新監視 / プロジェクト / 管理）
  - 配色・フォント（IBM Plex Sans JP / IBM Plex Mono）・インラインスタイルは元テンプレートから抽出した定義をそのまま使用
  - ダッシュボード統計・フィード・検索・文書・比較・レポート・プロジェクト・監査ログは実 API データを表示
  - FIT・チャット・更新監視は構造を完全準拠しつつ、実装可能な範囲（保存文献ベースのルール応答）で動作
- **管理画面に「システム設定」を追加**
  - DeepSeek / Anthropic の API キー入力欄・モデル名入力欄を実装
  - 「設定テスト」「設定保存」「入力クリア」「設定クリア」ボタンと、プロバイダごとの結果メッセージを表示
  - API キーは AES-256-GCM で暗号化して保存（画面・ログ・監査ログにキー値は出さない）
  - 要約・キーワード展開・比較生成の AI 呼び出しが DeepSeek（OpenAI 互換）/ Anthropic に対応し、設定済みプロバイダを優先利用
