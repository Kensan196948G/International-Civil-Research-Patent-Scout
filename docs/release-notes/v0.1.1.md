# Release Notes v0.1.1（2026-08-01）

## 概要

リリース直前の堅牢化・運用準備バージョン（Draft PR 時点の計画値）。

## 変更内容

- 認証エンドポイントにレート制限を追加（登録: IP あたり 10 回/時、ログイン: IP+メールあたり 10 回/15 分）
- メールアドレスの正規化（trim + 小文字化）
- 全レスポンスに `X-Request-Id` を付与し、エラーログにリクエスト ID を記録
- systemd 死活監視 timer（5 分間隔・失敗時自動再起動）を導入
- Dependabot（npm / GitHub Actions）設定を追加
- インシデント対応手順書・記録テンプレートを追加
- `npm run clean` を追加し、古い `tsbuildinfo` による差分ビルド不具合を防止
