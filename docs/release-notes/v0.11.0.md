# v0.11.0 — Cookie ベース認証

日付: 2026-08-12（PR 経由でマージ予定）

## 主な変更

- ログイン・登録・マジックリンク・Google SSO で HttpOnly Cookie（`icrps_token`）を設定
- CSRF ダブルサブミット（`icrps_csrf` Cookie + `X-CSRF-Token` ヘッダー）を Cookie 認証時のみ適用
- Web UI は localStorage へのトークン保存を廃止し、`credentials: include` でセッションを維持
- `POST /api/auth/logout` を追加（Cookie 削除）
- Bearer 認証は外部 API クライアント向けに維持

## セキュリティ効果

- XSS が発生しても HttpOnly Cookie の JWT は読み取れない
- クロスサイトからの状態変更リクエストは CSRF 検査で遮断

## テスト

- `apps/api/test/cookie-auth.test.ts`: CSRF ガード（Cookieなし/Bearer・欠落・不一致・一致・GET）、Cookie 設定、Cookie からの requireAuth
- `apps/web/test/api.test.ts`: credentials include・CSRF ヘッダー送信
