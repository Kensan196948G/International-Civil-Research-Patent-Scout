# v0.7.0 — チーム共有・プロジェクト権限

リリース日: 2026-08-05（ローカル本番適用済み）

## 追加機能

- **プロジェクト共有（チーム）**
  - メールアドレスでユーザーをプロジェクトへ招待（`project_members` テーブル）
  - ロール: viewer（閲覧）/ editor（編集）/ admin（管理）
  - オーナーは常に admin 相当。共有メンバーもプロジェクト一覧・文書・比較・レポートを利用可能
- **権限制御の適用**
  - 文書保存・比較生成・レポート生成: editor 以上
  - プロジェクト更新・メンバー管理: admin
  - 閲覧・エクスポート: viewer 以上
  - 検索のプロジェクト紐付けも共有メンバーに許可
- **メンバー管理 API**
  - `GET /api/projects/:id/members`
  - `POST /api/projects/:id/members`（メール＋ロール）
  - `PATCH /api/projects/:id/members/:userId`（ロール変更）
  - `DELETE /api/projects/:id/members/:userId`（削除）
- **UI**
  - プロジェクト画面に「チーム共有・メンバー管理」カード
  - メンバー一覧・ロール変更・削除・メールでの追加
  - 共有プロジェクトも一覧に表示（`listProjectsForUser`）
