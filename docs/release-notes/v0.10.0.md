# v0.10.0 — 本番運用強化（登録制御・AI コスト管理・レビュー・正直表示）

日付: 2026-08-12

## 主な変更

### セキュリティ・認証
- 登録制御: `REGISTRATION_MODE=domain` と `ALLOWED_EMAIL_DOMAINS` を追加。許可ドメイン以外の新規登録・Google SSO アカウント作成を 403 で拒否。
- 初回管理者ブートストラップ: `BOOTSTRAP_ADMIN_EMAIL` に一致する最初のユーザーを admin へ昇格（登録・ログイン・SSO の各経路）。
- Google SSO コールバックを JSON 返却から `APP_URL/login?token=...` へのリダイレクトへ変更（ブラウザフローが機能）。

### AI コスト管理・監査
- `llm_usage.user_id` へのユーザー帰属記録（検索展開・要約・比較・レポート・チャット）。
- ユーザー単位の 1 時間あたり AI レート制限（`AI_RATE_LIMIT_PER_HOUR`、既定 100、超過時 429）。
- 監査ログ API がユーザー名を JOIN して返却（管理画面の監査ログ表示を実名化）。
- AI 要約レビュー: `ai_summaries.status`（pending/approved/rejected/edited）とレビュー者・日時を記録。画面の「採用・却下・編集保存」が永続化され監査ログへ出力。

### 検索・データ品質
- 検索スキーマから未実装の `pdf` ソース種別を除外。
- 展開クエリを並列実行し、全体応答時間を短縮（外部 API の 8 秒タイムアウトを維持）。
- 検索失敗情報（failureSources）を UI に表示。

### UI/UX
- AI エンジン状態を実設定から動的表示（従来は「LLM キー未設定」固定）。
- ヘッダーの「全体を検索」を実際の検索画面連携へ接続。
- 適用可否チェックをサーバー側ルールベース API（`POST /api/fit`）へ接続し、入力が機能・結果は根拠文献付きで表示（「AI 判定」という誤表示を撤廃）。
- ダッシュボードの固定文言（選別 4 件・AI の所見・信頼度 0.91 等）を実データ・実モデル表示へ修正。
- レポートの「想定読者」を生成パラメータへ接続し、生成直後の Word/Excel/PDF 出力を可能に。
- 通知一覧を 60 秒間隔で自動更新。
- ダッシュボード統計・チャット参照範囲を共有プロジェクト/チームまで拡大。

### 移行
- `db/migrations/0010_ai_summary_review.sql` を適用（既存 `ai_summaries` は `pending` 扱いで後方互換）。

## テスト
- API 追加テスト: 登録ポリシー（ドメイン制限・レート設定）、適用可否チェック（fit）。
- Web テスト更新: 新 UI プロパティ対応。
- `npm run check`（typecheck / lint / test / build）全成功。
