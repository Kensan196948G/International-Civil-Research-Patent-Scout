# v0.9.0 — Meilisearch・チーム統計・認証拡張・LLM 使用量・レポート出力

リリース日: 2026-08-05（ローカル本番適用済み）

## 追加機能

- **Meilisearch 対応（検索エンジン抽象化）**
  - `MEILISEARCH_HOST` 設定時は Meilisearch で全文検索、未設定・障害時は PostgreSQL trigram へ自動フォールバック
  - 管理者 API `POST /api/admin/search/reindex`（全文献を Meilisearch へ再登録）
- **チーム招待メール**
  - チームメンバー追加時に招待メールを送信（Resend API 設定時）
- **チーム単位のダッシュボード・統計**
  - `GET /api/teams/:id/stats`（プロジェクト・メンバー・保存文献・レポート・比較表の件数）
  - プロジェクト画面のチーム管理カードに統計表示
- **認証拡張**
  - パスワードリセット（メール送信・トークン有効期限24h・使い捨て）
  - マジックリンクログイン（15分・一度だけ使用可能）
  - Google SSO（`GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` 設定時にログイン画面へ表示）
  - 新規 API: `/api/auth/forgot-password` `/reset-password` `/magic-link` `/magic-link/verify` `/sso`
- **LLM コスト・使用量ダッシュボード**
  - `llm_usage` テーブルに呼び出しごとのトークン・概算コストを記録（モデル別レート）
  - 管理画面に直近30日の呼び出し数・トークン・コスト・モデル別内訳を表示
  - 新規 API: `GET /api/admin/usage`
- **レポートの Word / Excel / PDF 出力**
  - Markdown→Word互換HTML（.doc）・Excel互換HTML（.xls）エクスポート
  - PDF は印刷用 HTML を開いてブラウザの印刷ダイアログで保存
  - `POST /api/reports/:id/export?format=markdown|word|excel|html`
