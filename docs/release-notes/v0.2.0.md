# v0.2.0 — 更新監視の実動化・AI レポート・通知センター

リリース日: 2026-08-05（開発版）

## 追加機能

- **更新監視（ウォッチ）の実動化**
  - 有効なウォッチテーマを対象に、論文・特許・Web を横断検索して新着候補を検知
  - 2時間ごとの systemd timer（`icrps-watch.timer`）＋手動実行（画面「今すぐ監視」/ `systemctl start icrps-watch.service`）
  - 初回実行は既存マッチをベースライン登録し、初回以降の新規マッチだけを未読通知にする
  - テーマの頻度（毎日/毎週/毎月）に応じた実行間隔制御
- **通知センター**
  - `notifications` テーブルと API（一覧・未読件数・既読化・全既読）
  - サイドメニュー「更新監視」に未読バッジ、ダッシュボードに未読通知数カード
  - ウォッチ画面に直近通知リスト（未読マーカー・出典リンク・既読化）
- **AI レポート本文生成**
  - LLM が保存文献・要約・比較表・検索条件から Markdown レポートを生成（出典番号付き）
  - LLM 未設定・失敗時は従来テンプレートへ自動フォールバック
  - レポート生成時にプロジェクト直近の検索条件と保存済み AI 要約を参照
- **検索の改善**
  - 展開キーワード（翻訳・同義語）を実際の横断検索クエリに反映（最大3クエリ・件数分散）
  - 検索履歴 API（`GET /api/search/history`）と検索画面の履歴表示（クリックで再検索）
  - 検索結果の CSV 出力
- **手動文献登録**
  - `POST /api/documents/import`（特許・論文・Web・PDF のメタデータ登録。URL/DOI/特許番号のいずれか必須・重複自動判定）
  - 技術文献フィードに「手動で文献を登録」フォーム（J-PlatPat / PATENTSCOPE / 社内資料など自動収集対象外の情報源向け）
- **パスワード変更**
  - `POST /api/auth/change-password`（現在のパスワード確認・bcrypt 再ハッシュ）
  - システム設定画面に全ユーザー向けパスワード変更カード
- **管理者統計**
  - `GET /api/admin/stats`（ユーザー・文献種別・検索/比較/レポート・ウォッチ・収集実行数）
  - 管理画面のカードを DB 文献数とウォッチ・収集の実績表示へ更新
- **レポート生成の追跡**
  - 監査ログにレポート生成モード（AI/テンプレート）・モデル・文献数を記録

## データベース

- `db/migrations/0004_notifications_watch_ext.sql`
  - `notifications` テーブル（user / watch_topic / source_document への外部キー、既読フラグ、未読インデックス）
  - `watch_topics.last_new_count` 列

## 残課題

- メール / Slack 通知（現在はアプリ内通知のみ）
- Cloudflare Workers 側の Cron Trigger / Queue 移行（要承認）
- 特許 DB（Espacenet OPS・Lens 等）の API 連携はキー設定後に追加検討
- 検索フィルター（国・年・種別）の UI 実装（API は対応済み）
