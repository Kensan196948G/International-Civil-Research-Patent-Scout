# v0.12.3 — アクセシビリティ（WCAG 2.1 AA）・ローカル PostgreSQL 対応

日付: 2026-08-31

## 主な変更

### アクセシビリティ（Issue #44 の Critical 2 / High 4 を解消）
- サイドバーナビゲーションを `<a onClick>` から `<button type="button">` へ変更し、キーボード・支援技術から操作可能に（`aria-current="page"` 付与）
- クリック可能な `div`（検索結果タイトル・関連文献・最近のプロジェクト等）を `<button>` 化
- ページタイトルを `<h1>`、各カード見出しを `<h2>/<h3>` へ変更し、画面全体に見出し階層を追加
- `<main id="icrps-main">` ランドマーク・スキップリンク・`<footer role="contentinfo">` を追加
- 未ラベル入力 18 件以上に `aria-label` / `htmlFor` を付与
- コントラスト不合格色を修正（プライマリ橙 `#E08A2B`→`#B25E0F`（白文字 4.67:1）、弱い文字色 `#8A97A8`→`#5F6B7C`（5.41:1）、アクティブ橙 `#B5701A`→`#9A5A0E` 等）
- `:focus-visible` のグローバルスタイルを追加し、入力欄の `outline:none` を除去
- モバイル（375px）で横スクロールなし・サイドバー全幅表示になるレスポンシブ対応
- `/reports` を `/report` のエイリアスとして追加（404 解消）

### ローカル PostgreSQL 対応（動作検証済み）
- `DATABASE_URL` のホストが neon.tech 以外の場合、`postgres.js`（TCP）で接続する分岐を `apps/api/src/db.ts` に追加
- 運用スクリプト（migrate / backup / verify-backup / verify-rollback / seed-demo / smoke-settings）を `scripts/lib/db.mjs` 経由に共通化
- ingest / watch CLI がローカル Postgres のコネクションプール保持で終了しない問題を `process.exit()` で解消
