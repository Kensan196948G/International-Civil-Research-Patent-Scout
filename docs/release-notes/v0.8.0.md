# v0.8.0 — 招待メール・オーナー移譲・チーム管理・引用グラフ拡張・全文検索/RAG

リリース日: 2026-08-05（ローカル本番適用済み）

## 追加機能

- **招待メール**
  - プロジェクトメンバー追加時に、プロジェクト名・ロール・URL を含む招待メールを送信（Resend API 設定時）
- **プロジェクトのオーナー移譲**
  - オーナーのみ実行可能（`POST /api/projects/:id/transfer`）
  - 移譲後、旧オーナーは admin メンバーとして自動的に残る
- **組織（チーム）単位の管理**
  - `teams` / `team_members` テーブルを追加
  - チーム作成・リネーム・メンバー追加/ロール変更/削除 API
  - プロジェクトをチームへ割り当て可能（`POST /api/projects/:id/team`）
  - チームメンバーはチーム所属プロジェクトへアクセス可能（`listProjectsForUser` / `getProjectAccess`）
- **引用ネットワークのグラフ拡張**
  - 引用元・参考文献の取得数を 20 件へ拡大
  - グラフ・一覧の表示数を「5件 / すべて（最大10件）」で切替
- **全文検索（PostgreSQL trigram）**
  - `pg_trgm` 拡張＋タイトル/要旨の GIN 索引を追加（マイグレーション 0008）
  - `searchDocumentsByText`（`similarity` 順のランキング検索）を実装
- **RAG チャットの拡張**
  - 保存文献が 3 件未満のとき、収集文献全体から関連文献を自動取得して回答に利用

## データベース

- `db/migrations/0008_teams_fulltext.sql`
  - `teams` / `team_members`
  - `research_projects.team_id`
  - `pg_trgm` + GIN 索引（title / abstract）

## API 追加

| メソッド | パス | 説明 |
| --- | --- | --- |
| POST | `/api/teams` | チーム作成 |
| GET | `/api/teams` | 自分のチーム一覧 |
| PATCH | `/api/teams/:id` | チーム名変更 |
| GET/POST | `/api/teams/:id/members` | メンバー一覧・追加 |
| PATCH/DELETE | `/api/teams/:id/members/:userId` | ロール変更・削除 |
| POST | `/api/projects/:id/transfer` | オーナー移譲 |
| POST | `/api/projects/:id/team` | チーム割当 |
