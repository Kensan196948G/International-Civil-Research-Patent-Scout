# v0.12.1 — 検索500修正・CSP/React警告対応・実ブラウザE2E

日付: 2026-08-14

## 主な変更

### バグ修正
- 横断検索・手動登録・ウォッチ監視で、外部コネクタが返す長い URL 等を `content_hash varchar(128)` へ直接 INSERT し 500 になる問題を修正
  - `normalizeContentHash`: 128 文字超は SHA-256 hex（64 文字）へ正規化（短い既存キーは互換のためそのまま）
  - `clampMeta`: DOI・特許番号・公開番号・出典名・国をカラム長へクランプ
  - 検索失敗時は `search_queries.status` を `failed` に更新し、UI が「実行中」のままにならないよう修正
- CSP が Google Fonts（fonts.googleapis.com / fonts.gstatic.com）をブロックしていた問題を修正（style-src / font-src に追加）
- チャット画面の map コールバック変数名ミス（`m is not defined`）を修正
- StandaloneView の React key 警告を解消（Fragment key 付与）

### 検証・スクリプト
- `scripts/ui-e2e.mjs` を追加（Firefox + Playwright による実ブラウザ E2E）
  - ログイン→ダッシュボード→フィード→文書詳細→検索→プロジェクト→比較→適用可否→レポート→チャット→ウォッチ→管理→システム設定→ログアウト
  - 実測: 全 14 項目 PASS・console error 0
- `npm run smoke:ui` を追加
