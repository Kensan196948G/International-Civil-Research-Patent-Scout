# v0.4.0 — 特許カード拡充・検索共有/ブックマーク・メール通知・類似文献検索

リリース日: 2026-08-05（ローカル本番適用済み）

## 追加機能

- **特許結果カードの拡充**
  - 検索結果に特許ステータス・出願人・発明者を表示
  - `source_documents.patent_status` 列を追加し、SerpAPI Google Patents / Espacenet OPS のステータス・出願人・発明者を保存
- **検索条件の保存・共有 URL・ブックマーク**
  - 検索条件を URL（`/search?q=...&types=...&from=...&to=...&countries=...`）で共有可能
  - 共有 URL を開くと条件が復元され自動検索
  - 検索履歴のブックマーク登録/解除（`search_queries.is_bookmarked`）
  - API: `GET /api/search/bookmarks` / `PATCH /api/search/:id/bookmark`
- **メール通知（Resend API・任意）**
  - ウォッチ新着を検知したらテーマ所有者へメール送信（タイトル・URL 一覧）
  - 文献収集失敗時は管理者メールへ通知
  - `RESEND_API_KEY` / `EMAIL_FROM` / `ADMIN_EMAIL` 未設定時は通知なし（既存動作維持）
- **類似文献検索**
  - 文書詳細の「引用ネットワーク」タブを、実データの類似文献ランキングへ変更
  - 日本語2グラム＋英単語のトークン一致（Jaccard×オーバーラップ）でスコアリング
  - API: `GET /api/documents/:id/similar`（クリックで対象文書へ遷移）
