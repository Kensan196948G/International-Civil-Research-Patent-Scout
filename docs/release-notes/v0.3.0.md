# v0.3.0 — 特許情報の深化（Espacenet OPS / Google Patents エンジン）

リリース日: 2026-08-05（ローカル本番適用済み）

## 追加機能

- **Espacenet OPS コネクタ**
  - EPO Open Patent Services（OAuth2 client_credentials）で特許を検索
  - 公開番号・タイトル（日英）・要約・出願人・発明者・公開日・国を取得
  - 公開日（`pd within`）・国（`pn`）フィルターを検索クエリに反映
  - 環境変数 `ESPACENET_OPS_KEY` / `ESPACENET_OPS_SECRET` 未設定時は自動スキップ（従来動作を維持）
- **SerpAPI Google Patents エンジン**
  - `SERP_API_KEY` 設定時に `engine=google_patents` を使用し、特許ステータス・出願人・発明者・公開日を取得
  - 未設定時は従来の Google Patents HTML パースへフォールバック
- **検索パイプラインへの組み込み**
  - 特許検索時、SerpAPI 設定時は Google Patents エンジン＋Espacenet OPS（キー設定時）を並列実行
  - 各コネクタの失敗は従来どおり分離され、他ソースの結果は維持

## 環境変数

```bash
# 任意（未設定時は該当コネクタを自動スキップ）
ESPACENET_OPS_URL=https://ops.epo.org/3.2
ESPACENET_OPS_KEY=
ESPACENET_OPS_SECRET=
SERP_API_KEY=
```
